# DartMini IDE

A premium, purely mobile-first Dart IDE built with Flutter.

## Features
- Deep black/dark gradient background UI
- Code Execution via OneCompiler or Custom API Presets
- Full syntax highlighting (flutter_code_editor)
- Examples Gallery, Code Formatting, Export/Import configurations

## Setup
To provide an API key for OneCompiler without hardcoding it in the repository, build and run the app with the `--dart-define` flag:

```bash
flutter run --dart-define=RAPIDAPI_KEY=your_key_here
```
